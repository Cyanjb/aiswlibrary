Alexander McQueen

What it means

British designer Alexander McQueen (1969-2010) mixed razor-sharp tailoring with dark, romantic drama: tartan, feathers, lace, skulls and runway shows that felt like theater.

When to use it

Use for dramatic, gothic and haunting fashion. It can tip into spooky fast, so add color words if you want it lighter.

Try this
