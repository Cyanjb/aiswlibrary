Bento Grid Layout

What it means

Content sits in a grid of rounded boxes of different sizes, like the little compartments in a bento lunch box. Soft spacing and gentle contrast make it easy to scan.

When to use it

Use for product feature pages, portfolios and personal link pages. If every box shouts at once it feels crowded, so keep a few big and the rest small.
