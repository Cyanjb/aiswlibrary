UI Components

Breadcrumbs

What it means

A trail of links at the top of a page, like Home > Library > Lighting, showing the path you took to get here. The last one is where you are, and clicking any earlier one takes you back there.

When to use it

Use it on sites with several levels, like libraries, shops or help centres. It adds little on a flat site with only a few pages.

Try this
"Add a breadcrumb trail above the page title that grows as I go deeper, highlights the current page and trims back when I click an earlier crumb."
