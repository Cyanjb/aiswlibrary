Brutalist Web Design

What it means

A raw, deliberately rough site inspired by bare concrete buildings: plain boxes, harsh lines, odd layouts and almost no decoration, set in Darker Grotesque.

When to use it

Use for art projects, zines, studios and brands that want to look rebellious and honest. Can confuse visitors who expect a normal, friendly shop.

Try this
"website for an underground record label, brutalist web design, plain grey boxes, harsh black text"
