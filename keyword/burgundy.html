Basic Color Spectrum

Burgundy

What it means

A deep, rich red with a hint of purple, like red wine in a glass.

When to use it

Use for elegant, romantic and moody scenes, from velvet chairs to winter fashion. In dark scenes it can read as black, so give it light.

Try this
"burgundy velvet gown in a candlelit hall"
