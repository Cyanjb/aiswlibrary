Contemporary Web Design

What it means

Today's tidy modern look: grids of boxes, an optional dark mode, clean Jost type and fast, easy-to-use layouts.

When to use it

Use for startups, apps and product sites that want to feel current. Because it is so common, it can blend in with many other sites.
