Dithered Web Design

What it means

Images and shading made from tiny dot patterns using only a few colors, like an old computer screen or newspaper print. This dotting trick is called dithering, and it looks high contrast and a little nostalgic.

When to use it

Use for music, art, tech zines and retro-flavored product pages. The dots can make small details and faces hard to read.
