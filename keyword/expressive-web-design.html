Web and App Design Styles

Expressive Web Design

What it means

A lively, personality-packed site with bold colors, playful graphics and shifting layouts, all set in the typewriter-like IBM Plex Mono font.

When to use it

Use for creative studios, events and youthful brands that still need clear structure. Can tire the eye if every section is loud.
