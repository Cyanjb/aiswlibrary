Floating Action Button

What it means

A round button that floats in the bottom corner of a phone screen for the main thing you do in the app, usually with a plus sign. Tapping it can turn the plus into an X and fan out a few smaller choices.

When to use it

Use it in mobile apps where one action matters most, like writing a new note. One per screen is plenty, and make sure it never covers important content.
