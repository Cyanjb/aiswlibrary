Web Motion and Effects

Horizontal Scroll

What it means

Scrolling down the page moves a row of big cards sideways across the screen instead. It turns a normal scroll into a sideways gallery or timeline.

When to use it

Use it for a timeline, a set of chapters or a portfolio row that deserves a moment of attention. It can confuse people on phones, so test it there and keep a simple fallback.

Try this
"When I scroll down, move this row of large cards sideways across the screen like a timeline"
