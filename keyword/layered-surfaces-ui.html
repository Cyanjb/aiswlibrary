Web and App Design Styles

Layered Surfaces UI

What it means

A tidy app look built from flat sheets stacked in layers, each with a soft shadow, plus colors that follow one theme and small smooth motions when you tap.

When to use it

Use for phone apps, dashboards and tools that need to work well on every screen size. Common enough that it can feel familiar rather than special.
