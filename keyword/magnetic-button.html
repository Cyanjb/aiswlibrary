Web Motion and Effects

Magnetic Button

What it means

A button that leans toward the mouse as it gets close, as if pulled by a magnet, then springs back when the mouse moves away. It squashes a little when clicked.

When to use it

Use it on one main call to action, the button you most want people to press, to make it feel alive. Keep it to one or two buttons per page.

Try this
"Make my main button lean toward the cursor when it gets close, spring back when it leaves, and squash slightly on click"
