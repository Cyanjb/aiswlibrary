Microgame Frenzy

What it means

A rapid-fire party game film: a shouted command word, a few seconds, one action, one result, and each tiny game drawn in a totally different art style. It keeps returning to the same show stage and gets faster every round.

When to use it

Great for speedrun reels, tool round-ups and fun list videos. It is chaotic on purpose, so it is not for anything that needs careful explaining.

"30-second round-up reel, microgame frenzy animation, shouted command word, quick tiny games in different art styles, speeding up each round"
