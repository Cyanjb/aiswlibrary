Modal Dialog

What it means

A box that pops up in the middle of the screen while the page behind it goes dark. It asks one question and waits for an answer, usually with two buttons.

When to use it

Use it to confirm something important, like deleting a list. Keep it rare, because a box that blocks the whole page gets annoying fast.
