Transitions and Editing

Movement Match Montage

What it means

The same movement repeated in different places, with each cut landing in the middle of the move.

When to use it

Use it for montages that need rhythm and a feeling that it is all one story. Ask for the same height and size in frame each time.

Try this
"a montage of a girl making the same jump on a beach, a rooftop and a forest path, each cut landing mid-jump at the same height in frame"
