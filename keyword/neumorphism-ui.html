Neumorphism UI

What it means

Soft buttons and cards that look pressed into, or pushed out of, the same smooth surface, using light and dark shadows on a single background color.

When to use it

Use for calm control panels, music players and smart home apps. Low contrast makes buttons hard for some people to see, so use it with care.
