Pictogram Motion

What it means

A sports-event style flash-card film: each card is one faceless stick-figure symbol doing one action on a big sun circle, with a huge heavy title and a small index number, over a grid pattern whose rows slide. Every cut lands on a drum hit.

When to use it

Great for lists, step-by-step tips and sporty, energetic brand reels. Each card holds one idea only, so it is not for long explanations.
