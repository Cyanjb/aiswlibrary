UI Components

Skeleton Screen

What it means

Soft grey blocks shaped like the page that show while content is still loading, with a gentle shine sweeping across. They then fade into the real pictures and text.

When to use it

Use it so a page feels fast and steady while it waits for data, instead of showing a blank screen. It only helps if the grey shapes match the real layout.

Try this
"While these cards load, show grey placeholder blocks in the same shapes with a soft shimmer sweeping across, then cross-fade into the real cards."
Pairs well with

loading spinner · empty state · layered surfaces ui
