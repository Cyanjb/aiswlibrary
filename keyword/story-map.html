Story Map

What it means

An illustrated map that follows one journey, with a winding path and little scenes drawn at each stop along the way. It tells a whole story in one picture.

When to use it

Use for adventures, children's books, travel memories and event posters. Keep the number of stops small so each scene stays clear.
