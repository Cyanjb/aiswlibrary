UI Components

Tooltip

What it means

A small label with a pointer arrow that fades in above something when you hover the mouse over it. It fades away when the mouse leaves.

When to use it

Use it to explain a small icon or setting in a few words. Phones have no hover, so never put must know information only in a tooltip.

Try this
"Add a tooltip to the info icon that fades in above it with a little pointer arrow and says Saves every 30 seconds"
Pairs well with

toggle switch · dropdown menu

Works in

claude-code · lovable · v0 · bolt
